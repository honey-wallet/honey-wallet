# Logo sources

Brand marks belong to their owners and are used here only to name each project.

- near, ethereum, base, solana, usdc, render, jupiter, ref, uniswap, crypto-com: [web3icons](https://github.com/0xa3k5/web3icons) (`@web3icons/core` 4.0.58, MIT)
- bittensor: the τ mark from bittensor.com, set on a white coin
- aerodrome: aerodrome.finance/images/AERO/logo-512.png
- reown: github.com/reown-com avatar
- nansen: github.com/nansen-ai avatar
- ethereum-coin: cryptocurrency-icons (CC0), via ~/video-harness/films/_kit/assets/crypto/eth.svg
- base-square: Base's current mark, the blue square (#0000FF), as in web3icons `svgs/networks/branded/base` (4.0.58); shown as a rounded square, not a coin
- base-coin (no longer used): the old Base circle-and-bar mark
- bittensor-coin: the τ mark on a black coin, to match the dark theme
- wallet-metamask, wallet-phantom, wallet-coinbase (Coinbase Wallet), wallet-sender (Sender, a NEAR wallet): [web3icons](https://github.com/0xa3k5/web3icons) (`@web3icons/core` 4.0.58, MIT), `svgs/wallets/background`
- github: Simple Icons (CC0), recoloured to the deck's text colour, via ~/video-harness/films/_portfolio/icons/github.svg
- bridge-stargate, bridge-across, bridge-debridge, bridge-axelar: [web3icons](https://github.com/0xa3k5/web3icons) (`@web3icons/core` 4.0.58, MIT), `svgs/tokens/background` (STG, ACX, DBR, AXL)
- ai-chatgpt: the OpenAI mark from Simple Icons (CC0, `simple-icons@15.0.0/icons/openai.svg`), white on black
- ai-claude: the Claude mark from Simple Icons (CC0), via ~/video-harness/films/_portfolio/icons/claude.svg, white on Claude orange
- ai-google: Google's four-colour "G" (as in Google's sign-in branding), on a dark tile
- jupiter-coin, ref-coin: [web3icons](https://github.com/0xa3k5/web3icons) (`@web3icons/core` 4.0.58, MIT), `svgs/tokens/background` (JUP, REF): the full-bleed coin versions, so the marks fill the coin like Uniswap's
